# Идеи: учеба и использование ИИ

Курс содержит занятия «Отбор идей», «Постановка задачи для любителей ИИ», «Проектирование информационной системы», «Диаграммы последовательностей».

## Как использовать ИИ с пользой

- 🔴 Просить ИИ играть проверяющего и задавать трудные вопросы к карточке.
- 🔴 Сохранять каждую версию вопросов и ответов в папку.
- 🟡 Просить ИИ найти слова без шага («ловец пустоты»).
- 🟡 Просить посчитать чувствительность модели, но проверять числа руками.
- ⚪ Просить ИИ пересказать карточку для ребенка.

## Что не отдавать ИИ

- Реальные разговоры, реальные числа и источники: их надо получить самому и проверить.
- Юридические выводы: их делает юрист.

## Связь с курсом

- 🟡 Для «диаграмм последовательностей»: нарисовать последовательность для пути платежа (3-024), справки (3-025), вопроса боту (3-026), ночного рейса (3-027).
- 🟡 Для «OAuth/OIDC»: описать, как согласие в приложении банка (3-025, 3-026) соотносится с этим протоколом.
- 🟡 Для «Регуляторные API»: сравнить с открытым банкингом из 3-025.
