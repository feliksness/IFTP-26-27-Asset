# Идеи: 3-025 единая финансовая платформа



## Продукт

- 🔴 Экран «Что делать сегодня»: одно действие (например, закрыть кредит, потому что вклад приносит меньше).
- 🔴 Калькулятор досрочного погашения на данных из всех банков.
- 🟡 Календарь платежей на месяц с цветом «хватит / не хватит».
- 🟡 «Тихий режим»: показывать только пугающие вещи (долг растет, вклад заканчивается).
- 🟡 Семейный режим: общая картина двух людей по согласию обоих.
- ⚪ Недельное письмо «ваши деньги за неделю».
- ⚪ Сравнение «ваш вклад против лучшего на рынке» с обязательной датой проверки.

## Справка для банка

- 🔴 Разные виды справки: короткая (доход за 3 месяца) и полная (6 месяцев).
- 🟡 Страница проверки справки для банка: ввел код, видит метки доверия и срок.
- 🟡 Справка для арендодателя или визового центра (не только для банка): отдельный продукт и цена.
- ⚪ Справка на двух языках.

## Доверие

- 🔴 Крупная кнопка «Отозвать все согласия» на главном экране.
- 🟡 Журнал «кто и когда видел мои данные» для самого человека.
- 🟡 Режим демо с вымышленными данными, чтобы попробовать без подключения.
- ⚪ Тест «насколько у вас упорядочены деньги» как заманивание (без хранения данных).

## Банки

- 🟡 Страница для банка «сколько ваших клиентов просили подключить вас» как аргумент.
- 🟡 Рейтинг прозрачности банков по доступности данных (по открытым критериям).
- ⚪ Хакатон для банков: придумать продукты на данных платформы.
