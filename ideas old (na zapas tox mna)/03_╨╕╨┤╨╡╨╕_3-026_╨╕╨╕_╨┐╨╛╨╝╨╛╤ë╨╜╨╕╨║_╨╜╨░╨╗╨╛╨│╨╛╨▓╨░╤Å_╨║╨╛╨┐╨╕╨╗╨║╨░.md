# Идеи: 3-026 налоговая копилка и помощник



## Продукт

- 🔴 Один экран: «Отложено / нужно к сроку / остается свободно».
- 🔴 Копилка с разными правилами: фиксированный процент, процент только с крупных оплат, «округлять вверх».
- 🟡 Предупреждение «до порога режима осталось N драм оборота».
- 🟡 Шаблон счета клиенту одним нажатием (черновик, подает сам клиент).
- 🟡 Режим «отпуск»: бот сам напоминает бухгалтеру, что клиент в отъезде.
- ⚪ Ответы бота голосом на армянском, русском и английском.
- ⚪ Игра «угадай срок» для обучения начинающих ИП.

## Бот и бухгалтер

- 🔴 Показывать клиенту, какое из четырех условий сработало («передаю бухгалтеру, потому что тема вне списка»).
- 🟡 Оценка ответа клиентом «помогло / не помогло» для настройки порога.
- 🟡 Еженедельный разбор: 5 вопросов, на которые бот ответил с наименьшей уверенностью.
- 🟡 Банк вопросов, которые никогда не должен отвечать бот (красный список).
- ⚪ Режим «объясни как ребенку» для сложной нормы (с обязательной ссылкой на закон).

## Рост

- 🔴 Начать с одной отрасли (салоны красоты), сделать шаблонные сроки и ответы под нее.
- 🟡 Партнерство с поставщиками материалов: бесплатный месяц при покупке.
- 🟡 Чат-сообщество ИП внутри сервиса.
- ⚪ Мерч с шутками про налоговые сроки.
