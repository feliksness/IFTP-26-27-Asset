# Глоссарий

- **Ячейка:** строка статистики по категории, району и неделе.
- **Порог:** показываем ячейку только при не менее 5 продавцах и без одного продавца свыше половины оборота.
- **HMAC:** хеш с секретным ключом, по коду нельзя восстановить кошелек.
- **Метка доверия:** пометка в справке, откуда данные (банк, проверенная выписка, со слов).
- **У1–У4:** четыре условия, при которых бот отвечает сам.
- **Копилка:** резерв налога на собственном накопительном счете клиента.
- **N:** минимальное число машин, при котором рейс окупается.
- **Поверенный счетчик:** счетчик с поверкой, по нему считаются литры.
